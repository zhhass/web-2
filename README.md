## How to publish on GitHub Pages

1. Create a new repository on GitHub (or reuse an existing empty one for this assignment).
2. Upload every file above directly into the repo root — no folders, just the flat file list.
3. Go to **Settings → Pages**, choose the `main` branch and `/root`, save.
4. Site goes live at `https://your-username.github.io/your-repo-name`.
